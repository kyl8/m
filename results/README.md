# Resultados validados

Esta pasta reúne dados selecionados das execuções de 8 de outubro de 2026 usados no relatório acadêmico.

- `resultados_validados.json`: ambiente, critérios e resultados resumidos;
- `escala.csv`: rajadas de uma mensagem por dispositivo;
- `batch.csv`: comparação de tamanhos de lote no InfluxDB;
- `frequencia.csv`: frequência solicitada e observada;
- `evidence/`: evidências JSON escolhidas entre as execuções bem-sucedidas.

Os arquivos não substituem uma nova execução. Horários, UUIDs e métricas mudam a cada ensaio. Credenciais não fazem parte desta pasta.
